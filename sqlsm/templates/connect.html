SQL Server Management

Kelola SQL Server di Windows Server 2012

Alat awal untuk melihat database, tabel, dan menjalankan query tanpa SSMS yang berat.

  1. Server — isi localhost jika SQL Server ada di mesin ini.
  2. Autentikasi — Windows Auth jika login Windows sudah punya akses; SQL Auth untuk user sa atau login SQL.
  3. Database — boleh master dulu, lalu pilih database lain setelah masuk.

Jangan pakai Internet Explorer. Chrome 109 atau Firefox ESR cukup untuk Windows Server 2012.
