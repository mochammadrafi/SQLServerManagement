Cara memakai

        
      

      

        
Beberapa koneksi

        
Pilih koneksi di header, atau Koneksi baru untuk server lain tanpa memutus yang sudah ada. Putuskan hanya menutup koneksi yang sedang dipakai.

        
Jelajah (tanpa SQL)

        
Klik database, lalu klik tabel atau view. Datanya langsung tampil. Klik satu baris untuk membuka viewer. Double-click sel untuk nilai penuh.

        
Tabel besar (100 juta+ baris)

        
Aplikasi tidak pernah memuat seluruh tabel. Yang tampil hanya satu halaman (100–1000 baris). Jumlah baris diambil dari statistik partisi, bukan COUNT(*). Filter WHERE di tabel ratusan juta memakai TOP + FAST tanpa ORDER BY, supaya baris pertama langsung keluar. Export memakai pola yang sama.

        
Export / backup

        
Dari kartu database: Backup (.bak) atau Export semua tabel (CSV). Dari kartu tabel: Export tabel itu saja. Nama file bisa diubah sebelum mulai. Beberapa export bisa jalan bersamaan. Tabel yang sedang diexport bisa dibatalkan sendiri; job tetap lanjut dan hasilnya masuk riwayat. File yang sudah tertulis tetap bisa diunduh. Progress, jeda, dan batal ada di Export di header.

        
SQL

        
Mode SQL untuk query ad-hoc. SELECT tanpa TOP dipotong otomatis 1000 baris di server. F5 / Ctrl+Enter menjalankan SQL. Batalkan atau Esc menghentikan query yang sedang jalan.

        
Hati-hati

        
DELETE / UPDATE / DROP jalan apa adanya. Tidak ada undo.
