Cara memakai

        
      

      

        
Tabel besar (100 juta+ baris)

        
Aplikasi tidak pernah memuat seluruh tabel. Yang tampil hanya satu halaman (100–1000 baris) lewat keyset paging. Jumlah baris diambil dari statistik partisi, bukan COUNT(*).

        
Export / backup

        
Pilih folder tujuan di server. Export CSV bisa dipecah per ukuran (default 10 GB) atau per baris. Backup database menulis file .bak ke folder yang sama; pecahan 10 GB memakai beberapa file stripe SQL Server.

        
Query

        
Jangan SELECT * tanpa TOP pada tabel besar. Hasil query ad-hoc tetap dipotong 1000 baris. Batch GO didukung. F5 / Ctrl+Enter menjalankan SQL.

        
Hati-hati

        
DELETE / UPDATE / DROP jalan apa adanya. Tidak ada undo.
